# グラフィックス

品質ティア、ガンマ、レンダースケール、ポストエフェクトのトグル、ハードウェアアップスケーリング。これらは
**Apply ボタン**で適用されます — 品質ティアの変更はレンダーターゲットを再割り当てするので、誰かがドロップダウンを
スクロールしている間に起きてほしくないものです。

## パイプラインの認識

WagSettings は Built-in パイプライン、URP、HDRP で動き、そのどれも参照**しません**。URP を参照すれば、WagSettings は
Built-in プロジェクトでコンパイルを拒むことになります — どこでも動かなければならないアセットには受け入れられません。

代わりに、パイプラインはアクティブなアセットの型名から識別されます。

```csharp
RenderPipelineKind kind = applier.Pipeline;   // BuiltIn, Universal, HighDefinition or Custom
```

認識できないスクリプタブルパイプラインは `BuiltIn` ではなく `Custom` として報告されるので、持っていないかもしれない
機能を提示されることはありません。

### 各パイプラインが対応するもの

| 機能 | Built-in | URP | HDRP | Custom |
|---|:--:|:--:|:--:|:--:|
| 品質ティア | ✅ | ✅ | ✅ | ✅ |
| ガンマ | ✅ | ✅ | ✅ | ✅ |
| レンダースケール | ❌ | ✅ | ❌ | ❌ |
| ブルーム / AO / モーションブラー | ✅ | ✅ | ✅ | ✅ |
| アップスケーリング (DLSS / FSR) | ❌ | ✅ | ✅ | ❌ |

レンダースケールは URP アセットのプロパティです。HDRP には代わりに動的解像度があります。アップスケーリングには
スクリプタブルパイプラインが必要です。

**利用できない機能は警告付きでスキップされ、例外にはなりません。** パイプラインをまたいで 1 つの設定メニューを
出荷するプロジェクトも、後でパイプラインを切り替えるプロジェクトも動き続けます。表示する前に尋ねてください。

```csharp
renderScaleSlider.SetEnabled(applier.SupportsFeature(GraphicsFeature.RenderScale));
```

警告は機能ごとに一度だけ発生し、適用のたびではありません。

## 設定

すべてのキーは任意です。空にしておけば、その側面は管理されません。

| 設定 | 型 | キー | 注記 |
|---|---|---|---|
| 品質ティア | `IntSetting` | `graphics.qualityTier` | Project Settings → Quality へのインデックス。プロジェクトが定義する範囲に丸める。 |
| ガンマ | `FloatSetting` | `graphics.gamma` | グローバルシェーダー float として公開。 |
| レンダースケール | `FloatSetting` | `graphics.renderScale` | URP のみ。0.1–2 に丸める。 |
| アップスケーリング | `IntSetting` / `EnumSetting` | `graphics.upscaling` | 独自の値。イベントとして発生。**オプトイン**: 利用可能なアップスケーラーはパイプラインに依存するので、キーは既定で空。 |
| ブルーム | `BoolSetting` | `graphics.bloom` | |
| アンビエントオクルージョン | `BoolSetting` | `graphics.ambientOcclusion` | |
| モーションブラー | `BoolSetting` | `graphics.motionBlur` | |

## ポストエフェクト: WagSettings が公開し、あなたが適用する

ブルームは URP や HDRP の **Volume プロファイル**、または Built-in パイプラインのポストプロセッシングスタックに
あります。そのどれかに手を伸ばせば、プロジェクトが持っていないかもしれないパッケージへの強い依存になります。
そこで WagSettings は値を 2 つの方法で公開し、あなたに接続させます。

1. **グローバルシェーダー float**。`1` または `0` に設定 — 直接読むシェーダー向け。
2. **`UnityEvent<bool>`**。インスペクターで Volume コンポーネント、ポストプロセッシングレイヤー、または独自の
   メソッドに配線。

```csharp
public void SetBloom(bool enabled)
{
    if (_volume.profile.TryGet(out Bloom bloom))
    {
        bloom.active = enabled;
    }
}
```

そのメソッドをインスペクターでトグルのイベントに落とせば完了です。アップスケーリングも同じです。選ばれた値は
パイプラインの DLSS や FSR の設定のためにイベントとして発生します。

これは意図的なトレードオフです — 少しの配線と引き換えに、どんなプロジェクトにもインストールできるアセットを。

## ガンマ

パイプラインに依存しないガンマ制御はないので、ガンマはグローバルシェーダー float、既定では `_WagSettingsGamma`
として公開されます。カラーグレーディングシェーダーで読むか、同じイベントパターンで URP/HDRP の `LiftGammaGain`
オーバーライドに渡してください。プロパティ名は設定可能です。

## セットアップ

1. 欲しい設定を作り、`SettingsProfile` に追加する。
2. **Add Component → WaggleBum → WagSettings → Quality Applier**。最初に追加したとき、ブルーム、アンビエント
   オクルージョン、モーションブラーのトグルをシードします。
3. 各トグルのイベントを、その効果を持つものに配線する。
4. **WagSettings Manager** の下に置く。マネージャーが起動時に接続します。

## 例外を投げるもの、警告だけのもの

| 状況 | 結果 |
|---|---|
| プロファイルにないキーを参照するトグル | **例外** — `KeyNotFoundException` |
| プロジェクトのレベル外の品質ティア | **丸める** — より多くのレベルを持つビルドで保存されたティアでクラッシュしてはならない |
| 0.1–2 の範囲外のレンダースケール | **丸める** |
| パイプラインにない機能 | **一度警告**し、スキップ |
| `renderScale` プロパティのないパイプラインアセットでのレンダースケール | **一度警告**し、スキップ |

## 適用モード

既定は `OnApply` です。ガンマをライブでプレビューしたければ、ガンマキーだけを埋めた `Immediate` の独自の
`QualityApplier` を与えてください — [拡張性](../Extensibility.md)を参照してください。
