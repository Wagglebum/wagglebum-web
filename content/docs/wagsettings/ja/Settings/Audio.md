# オーディオ

WagSettings は設定から `AudioMixer` を駆動し、各リニアな音量スライダーをミキサーが実際に期待するデシベルに
変換します。音量はプレイヤーがドラッグする間ライブで適用されます — レベルを選ぶ唯一のまともな方法です。

## 変換が重要な理由

ミキサーは**デシベル**で動き、これは対数です。スライダーは**リニア**です。スライダーの値を `AudioMixer.SetFloat`
にそのまま渡すと、古典的なバグになります。スライダーの下半分は同じに聞こえ、聞き取れる変化はすべて上の 1 割に
押し込められます。

`AudioVolume` がその対応付け `20·log₁₀(x)` を行い、下限は −80 dB です。

| スライダー | デシベル |
|---|---|
| `1.0` | `0 dB` — フル音量 |
| `0.5` | `−6.02 dB` — 半分の大きさ |
| `0.25` | `−12.04 dB` |
| `0.0` | `−80 dB` — 無音 |

```csharp
float decibels = AudioVolume.LinearToDecibels(0.5f);   // -6.0206
float slider   = AudioVolume.DecibelsToLinear(-6.02f); //  0.5
```

これは `UnityEngine` に依存せず `Runtime/Core` にあるので、単独で使え、テストできます。

## 近道

Audio にチェックを入れて **Tools → WaggleBum → WagSettings → Setup** を実行します。4 つのオーディオ設定を生成し、
Master、Music、SFX グループとそれらの音量が公開済みのミキサーをクローンし、アプライヤーの既定値は両方に一致します。
マネージャーの下に Audio Mixer Applier を追加し、`WagSettingsMixer` を割り当ててください。[セットアップ](../Setup.md)を
参照してください。

このページの残りは、それがあなたのために何をしているか — 違うやり方をしたいときのために — です。

## 手作業でセットアップする

**1. ミキサーパラメーターを公開する。** `AudioMixer` でグループを選び、Inspector の **Volume** フィールドを右クリックして
**Expose 'Volume (of Group)' to script** を選びます。次に Audio Mixer ウィンドウの **Exposed Parameters** ドロップダウンで、
安定した名前 — `MasterVolume`、`MusicVolume` など — に変更します。

> この手順が人が見落とすものです。公開されていないパラメーターはプレイヤーのスライダーが黙って何もしないことを
> 意味するので、WagSettings は静かに失敗せず、パラメーター名を添えて例外を投げます。

**2. 設定を作る。** バスごとに `FloatSetting`、任意でミュートトグルごとに `BoolSetting`:

| 設定 | 型 | キー | 既定値 |
|---|---|---|---|
| マスター音量 | `FloatSetting` | `audio.master` | `1` |
| マスターミュート | `BoolSetting` | `audio.master.mute` | `false` |
| 音楽音量 | `FloatSetting` | `audio.music` | `0.8` |
| SFX 音量 | `FloatSetting` | `audio.sfx` | `1` |

これらを `SettingsProfile` に追加します。

**3. アプライヤーを追加する。** *Add Component → WaggleBum → WagSettings → Audio Mixer Applier*。最初に追加したとき
3 つのバス — ミュート付きのマスター、ミュートなしの音楽と SFX — をシードします。これは上の設定そのもので、同梱の
ミキサーテンプレートが公開するグループなので、一般的なケースでは何も入力する必要がありません。ミキサーを割り当て、
各バスについて:

| フィールド | 意味 |
|---|---|
| **Volume Key** | このバスの 0–1 の音量を持つ float 設定のキー。**空ならこのバスをスキップ。** |
| **Mute Key** | バスをミュートする bool 設定のキー。ミュートトグルがなければ空。 |
| **Exposed Parameter** | ミキサーで公開した名前。例: `MasterVolume`。 |

使わないバスの音量キーを空にすればスキップされます。ボイスや UI のバスが欲しい? バスを追加し、設定を与え、
パラメーターを公開してください — アプライヤーは設定が存在しないバスをシードしません。`Attach` は欠けたキーで
例外を投げ、刈り込むまで例外を投げ続ける新しいコンポーネントは悪い既定だからです。

**4. WagSettings Manager の下に置く。** マネージャーは起動時にその下のすべてのアプライヤーを接続します。呼ぶものは
ありません。別の場所に置かなければならないアプライヤーは `WagSettings.Manager.Attach(applier)` で。

## ミュート

ミュートは**保存された音量に触れずに**バスを −80 dB に駆動するので、ミュート解除はプレイヤーが選んだレベルを正確に
復元します。ミュート設定はほかと同様に永続化されるので、ミュートで終了したプレイヤーはミュートで始まります。

## 例外を投げるもの、その理由

オーディオの設定ミスは本質的に静かです — 何もしないスライダーは、壊れたセットアップではなく壊れたゲームに見えます。
だからこれらは大きな音を立てます。

| 状況 | 結果 |
|---|---|
| 公開パラメーターがミキサーに見つからない | パラメーターと公開方法を名指しする `InvalidOperationException` |
| 音量キーはあるが公開パラメーターがないバス | バスを名指しする `InvalidOperationException` |
| プロファイルにないキーを参照するバス | `KeyNotFoundException` |
| ミキサーが未割り当て | GameObject を名指しする `InvalidOperationException` |
| 音量キーが**空**のバス | スキップ — そのバスを使わないプロジェクトであり、エラーではない |

## 適用モード

オーディオの既定は `Immediate` なので、プレイヤーはドラッグしながら変化を聞きます。音量変更を Apply ボタンまで
遅らせる良い理由はありません — モードについては[拡張性](../Extensibility.md)を参照してください。

## 独自のバスを追加する

バスは単なる設定です。項目を追加し、float 設定と公開パラメーターに向ければ動きます — コードなしで。`AudioMixer` の
パラメーターでないものを駆動するには、アプライヤーを書いてください。[拡張性](../Extensibility.md)を参照してください。
