# エディターウィンドウ

**Tools → WaggleBum → WagSettings → Editor**

1 つのウィンドウで、WagSave のものと同じ形です。両方を持つ開発者は 1 つのレイアウトを覚えるだけで済みます。

```
┌────────────────────┬──────────────────────────────────────────────┐
│ [logo] WagSettings │ Setup                                 [Docs] │
│────────────────────│──────────────────────────────────────────────│
│ ▸ Summary          │  the page                     │ its docs,    │
│   Setup            │                               │ in your      │
│   Settings Profile │                               │ language     │
│   Debugger         │                               │              │
│   Help             │                               │              │
│ v0.9.0             │                               │              │
└────────────────────┴───────────────────────────────┴──────────────┘
```

![Summary ページを表示したエディターウィンドウ: レール、ページ、ドキュメントペイン](../Images/editor-window-summary.png)

- 左の**レール**にページが並びます。前回開いていたページが開きます。
- 右の**ドキュメントペイン**は今見ているページを説明します。ドラッグで広げたり狭めたり、ヘッダーの **Docs** で
  オフにできます。どちらも記憶されます。
- **Summary** は状態です。プロジェクトに何があるか、セットアップが生成するものがすでに揃っているか、手作業で
  残っているものは何か。ここではプロジェクトは何も変わりません。
- **Setup** は選択です。何を生成するか、プレビュー、Generate。*Tools → WaggleBum → WagSettings → Setup* は
  このページでエディターを開くので、以前のリンクはすべてそのまま使えます。生成すると Summary に移動します。
- **Settings Profile** は「独自の設定を追加する」場所です。どのプロファイルが既定か、その中のすべての設定とキー、種類、
  既定値、範囲、並べ替えと削除、そして **設定を追加** — プロファイルの隣に新しい設定アセットを作るダイアログで、
  キーは入力中にチェックされます。[拡張性](Extensibility.md) を参照してください。
- **Debugger** はプレイモードでライブです。すべての設定の保留値、Apply / Revert / Reset、マネージャーが接続した
  アプライヤー。毎秒 4 回ポーリングし、何かが動いたときだけ再描画します。
- **Help** にはバージョン、チートシート、両方の Quick Start シーン、エディターの言語があります。

![プロファイルのすべての設定を一覧する Settings Profile ページ](../Images/settings-profile-page.png)

![Play モードの Debugger、保留中の値が太字](../Images/debugger-play-mode.png)

## 初回起動

`SettingsProfile` がまったくないプロジェクトでは、レールの代わりに 1 つの画面が表示されます。ロゴ、一文、
そして **Run Setup**。まだ存在しない設定についてのページのレールは、ノイズでしかありません。

## 言語

エディターは Help ページで選んだ言語に従います。選ぶまでは WagSave に設定された言語に従うので、両方を
インストールしていれば一度選ぶだけで済みます。翻訳が欠けている箇所は英語で表示されます — まだ翻訳されていない
文字列は英語で現れ、空白やキーになることはありません。

![エディター言語のドロップダウンを開いた Help ページ](../Images/help-language.png)

## 興味のある方へ

各ページは `EditorContent`、レールは `EditorPages`、ウィンドウが記憶するものは `IEditorPreferences` の継ぎ目の上の
`EditorWindowState`、ページのドキュメントは `EditorDocs` で、`<Page>.<locale>.md`、次に `.en.md`、次に `.md` を
試します。文字列は `Editor/Localization/<locale>.json` の上の `WagSettingsL10n` から来ます。これらはすべて
テスト付きの素のクラスです。ウィンドウ自体だけが、目で見て確認しなければならないものです。
